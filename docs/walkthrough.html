Agent Policy evaluates structured operations against an explicit policy, explains the matching rule, and leaves the actual operation untouched. Click around and watch the decision source change.

A decision has three receipts

Inputpolicy + request digests
Matchrule identity + position
Outcomeallow, deny, or default
Boundaryevaluation only; no execution
Browser model: this fixture is synthetic and local to this page. It demonstrates the explanation shape without claiming to intercept a process. Real enforcement belongs to a platform sandbox such as bubblewrap, a container, or a VM.

Try the same shape from a terminal

The commands below match the repository’s current CLI and synthetic fixtures.

git clone https://github.com/jonah-ux/agent-policy.git
cd agent-policy
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install .
agent-policy dry-run --policy examples/policy.json --request examples/request.json --receipt
agent-policy explain --policy examples/policy.json --request examples/request.json --receipt
agent-policy compose --policy examples/policy.json > effective-policy.json
